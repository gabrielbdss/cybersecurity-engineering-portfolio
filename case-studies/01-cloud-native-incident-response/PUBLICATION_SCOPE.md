## Evidence classifications

- **OBSERVED:** request or outcome appears in the supplied evidence model.
- **VERIFIED:** independently corroborated within defined scope.
- **INFERRED:** reasoning supported by indirect evidence but not conclusively demonstrated.
- **UNVERIFIED:** insufficient evidence for the claim.

The documented finding is intentionally limited: a security-relevant event can be denied without demonstrating compromise, data exfiltration or persistent unauthorized access. The public text expressly avoids universal assertions of security or forensic attribution.
