## Engineering questions

- How can telemetry, runtime metadata and build records be correlated without treating configuration as proof of actual serving?
- What can historical model-usage data prove when request ownership remains unattributed?
- How do logging scope, access permissions and retention affect confidence in conclusions?
- When should a preliminary inventory be accepted while deployment, migration and other production changes remain on HOLD?
